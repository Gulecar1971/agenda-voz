# Agenda Voz

Agenda personal para Android con lectura en voz alta.

- Vista Hoy / Semana / Mes
- Botón "Escuchar mi día" y widget de dos botones (abrir / escuchar)
- Avisos previos y a la hora, con voz
- Al tachar una tarea te dice la próxima
- Dictado por voz para cargar tareas

La app se compila sola en GitHub Actions y se publica en "Releases" como AgendaVoz.apk.
